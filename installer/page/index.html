Grok Puck

Install the Grok Puck firmware

Put the desk display's firmware on a Waveshare ESP32-S3-Touch-LCD-1.46 from this page, with nothing to install on your computer.

What you need

  • Chrome, Edge or Firefox (151 or newer) on a computer (Windows, macOS or Linux): installing uses Web Serial, which they have. Firefox first asks you to allow it for this site. The page offers Install only in a browser that can do it.
  • The board, and a USB-C cable that carries data: some cables only charge. The board needs no driver.

Install

  1. Plug the board into the computer. Close anything else that uses its port, such as idf.py monitor.
  2. Press Install and choose the board's port (on Windows it is called "USB JTAG/serial debug unit").
  3. Choose Install Grok Puck. Leave Erase device unticked to keep the device's settings, press Next, then Install. It takes about two minutes: keep this tab in front meanwhile.

Checking whether this browser can install…

This browser can't install firmware. Installing needs Web Serial, which this browser doesn't have. Open this page in Chrome, Edge or Firefox (151 or newer) on a computer.

This page isn't on a secure (HTTPS) address. Browsers let a page reach a USB device only over HTTPS, or from the computer itself (localhost). Open this page from its https:// address.

What happens next

  • A new or erased device shows a QR code for its setup network, Desk-Setup-XXXX. Join it with your phone and continue at step 4 of the setup guide: add your Wi-Fi and the bridge address, then approve the device in the bridge's admin page. If the setup page doesn't open by itself on the phone, open http://192.168.4.1 in the phone's browser.
  • A device that was already set up restarts with the new firmware and reconnects by itself. Its card in the admin page shows the new version.

Keep or erase the settings

An install keeps what the device has saved: its Wi-Fi networks, the bridge address and its key. Erase device clears all of it for a clean start: for the first install over Waveshare's demo firmware, or to set a device up again from scratch. An erased device then needs its Wi-Fi from your phone and approving again in the admin page.

If it doesn't work

The installer can't connect, or no port shows up
Hold the board's BOOT button while you plug it in, then press Install again. After the install, unplug it and plug it in again to start the new firmware.
"Failed to open serial port", or the port is busy
Close anything else using the port, such as idf.py monitor, a serial terminal, or another tab with this page.
Still nothing
Try another cable (some only charge) or another USB port.
The screen stays dark after the install
Unplug the board and plug it in again.
